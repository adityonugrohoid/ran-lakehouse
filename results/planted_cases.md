# Planted data-quality cases

Every data-quality case of rule D, planted on purpose in the synthetic demo run (12 weeks): what was planted, what the pipeline did, and the tests that fail when the property breaks (rule E3). Gathered by `python -m ran_lakehouse.lake.planted_report` from `bronze_backfill.json`, `silver_build.json`, `gold_build.json`, `time_travel_lineage.json`; the planted positions are evaluation-only (rule A3), so counts per kind only. "Silver scope" leaves out the first and last period of the delivered span.
